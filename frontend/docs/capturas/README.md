# Capturas del segundo avance

Capturas reales del frontend tomadas el **3 de noviembre de 2026** en modo de
revisión de maquetación. Cubren los 12 módulos de la matriz del README principal.

- Escritorio: ventana de 1366 × 768 px.
- Móvil: ventana de 390 × 844 px.
- Las páginas completas incluyen el contenido que requiere desplazamiento vertical.
- Los modales conservan su desplazamiento interno; el formulario de contacto incluye una captura de su sección inferior.
- Los guiones son contenedores vacíos del diseño. No se usaron registros ficticios ni operaciones de la API.
- Las imágenes documentan la presentación visual. La integración pendiente corresponde a Sprint 3.
